# FinEdge Machine Learning Pipeline (IEEE-CIS Fraud Detection)

This directory contains the data science workflow for the FinEdge AI Fraud Detection model.

## 1. Dataset Overview

The pipeline is trained on the benchmark **IEEE-CIS Fraud Detection Dataset** provided by Vesta Corporation / Kaggle.

* **Target Variable:** `isFraud` (Binary: `0` = Legitimate, `1` = Fraudulent)
* **Class Imbalance:** ~3.5% Fraud, 96.5% Legitimate
* **Files:**
  * `train_transaction.csv`: 590,540 rows × 394 columns (Transaction ID, Amount, ProductCD, Card features, Time offset `TransactionDT`, V-columns V1-V339)
  * `train_identity.csv`: 144,233 rows × 41 columns (Device info, OS, Browser, Network features)

---

## 2. Dataset Setup Instructions

Due to Kaggle dataset license policies, the raw CSV files are not committed to Git. Please follow these steps to set up the raw dataset:

1. Visit the Kaggle competition page: [IEEE-CIS Fraud Detection](https://www.kaggle.com/c/ieee-fraud-detection/data)
2. Download `train_transaction.csv.zip` and `train_identity.csv.zip`.
3. Extract both CSV files into the `ml/data/raw/` directory:
   ```text
   ml/data/raw/
   ├── .gitkeep
   ├── train_transaction.csv  (~683 MB)
   └── train_identity.csv     (~68 MB)
   ```

## 3. Directory Structure

```text
ml/
├── data/
│   ├── raw/                  <-- Place train_transaction.csv and train_identity.csv here
│   └── processed/            <-- Preprocessed train/val datasets generated by clean_data.py
├── notebooks/
│   ├── 01_eda.ipynb          <-- Exploratory Data Analysis notebook
│   └── eda.py                <-- Executable Python EDA script
├── preprocessing/
│   ├── load_data.py          <-- Data loading and left-join merger
│   ├── clean_data.py         <-- Missing value handling and sentinel encoding
│   └── feature_engineering.py<-- Derived features and leakage-safe preprocessing pipeline
├── training/                 <-- Model training scripts (Step 12)
├── evaluation/               <-- PR-AUC, ROC-AUC, and confusion matrix evaluation (Step 12)
├── artifacts/                <-- Saved trained model binaries (.pkl, .joblib)
└── requirements.txt          <-- Python ML dependencies
```

## 4. Quickstart Guide

### Step 4.1: Set Up Python Virtual Environment
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

pip install -r ml/requirements.txt
```

### Step 4.2: Run Exploratory Data Analysis (EDA)
```bash
python ml/notebooks/eda.py
```

### Step 4.3: Test Preprocessing Pipeline
```bash
python -m ml.preprocessing.feature_engineering
```

---

## 5. Step 12: Training & Evaluation

### Step 5.1: Install Updated Requirements (includes xgboost)
```bash
pip install -r ml/requirements.txt
```

### Step 5.2: Train All Three Models
```bash
python -m ml.training.train_models
```
Outputs:
- `ml/artifacts/logistic_regression_v1.pkl`
- `ml/artifacts/lr_preprocessor_v1.pkl`
- `ml/artifacts/random_forest_v1.pkl`
- `ml/artifacts/tree_preprocessor_v1.pkl`
- `ml/artifacts/xgboost_v1.pkl` *(if xgboost installed)*
- `ml/artifacts/model_metadata.json`

> **Note**: If Kaggle CSVs are not present in `ml/data/raw/`, the script automatically
> uses a synthetic dataset and clearly logs `SYNTHETIC DATA MODE`. Download the real
> dataset from Kaggle for meaningful results.

### Step 5.3: Evaluate All Three Models
```bash
python -m ml.evaluation.evaluate_models
```
Outputs:
- Comparison table (console + `ml/evaluation/model_comparison.csv`)
- Confusion matrices per model (text form)
- Model selection recommendation

### Step 5.4: Review Model Selection
See `ml/evaluation/model_selection.md` for the justified model selection writeup
and the exact artifact filename chosen for Step 13 integration.
